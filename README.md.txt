# HR Analytics – Employee Performance & Attrition Analysis (Excel Project)

## Project Overview
This beginner-level HR Analytics project uses Microsoft Excel to analyze employee performance, training, absenteeism, and attrition trends. The goal is to practice HR KPI analysis using pivot tables, charts, and basic formulas.

## Objectives
- Analyze employee attrition trends
- Study performance rating distribution
- Examine training hours vs performance
- Identify absenteeism patterns
- Provide HR recommendations based on insights

## Tools Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Basic Excel formulas (IF, COUNTIF, AVERAGEIFS)

## Dataset
The dataset contains the following fields:
- Employee ID  
- Age  
- Gender  
- Department  
- Job Role  
- Years at Company  
- Performance Rating (1–5)  
- Training Hours  
- Absenteeism Days  
- Attrition (Yes/No)  

## Key Analysis Performed
- Attrition Rate by Department
- Average Performance Rating by Job Role
- Training Hours vs Performance
- Absenteeism Trend by Department
- Gender-wise Attrition Analysis

## Findings
- Higher attrition observed in Sales and Support departments  
- Employees with more training hours showed better performance ratings  
- Higher absenteeism linked with lower performance  

## Recommendations
- Improve training programs in high-attrition departments  
- Introduce engagement initiatives for employees with high absenteeism  
- Monitor performance trends regularly
